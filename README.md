# LOGOVO Barbershop
A men's barbershop in Astana, built with plain HTML and Bootstrap.

## Team:
- Abylay Utemis — services.html, booking.html
- Rustem Gazymbekov — about.html, gallery.html
- Alfarabi — team.html, history.html
- index.html and `css/custom.css` — made together


## Repository structure
```
/
├── index.html          — home page
├── services.html       — services and price list (Abylay)
├── booking.html        — booking form (Abylay)
├── team.html           — our barbers and their prices (Alfarabi)
├── history.html        — history of LOGOVO and the wolf emblem (Alfarabi)
├── about.html          — about us, interview with the barber (Rustem)
├── gallery.html        — photo gallery (Rustem)
├── css/
│   ├── custom.css      — our whole stylesheet, 68 lines
│   └── REMOVED.md      — what we deleted and what replaced it
├── images/             — our photos and the logo
├── screenshots/
│   ├── bootstrap/      — assignment 3
│   ├── before/         — assignment 2, pages before CSS
│   └── after/          — assignment 2, pages after CSS
├── sketches/           — folder for the hand-drawn sketches
└── report/             — PDF report from assignment 1
```

## How to open
Open `index.html` in a browser

## Validation
All seven pages pass the [W3C HTML validator](https://validator.w3.org/) with
zero errors, and `css/custom.css` passes the
[W3C CSS validator](https://jigsaw.w3.org/css-validator/) with zero errors.
