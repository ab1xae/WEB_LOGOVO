# LOGOVO Barbershop

Student project for the course "Introduction to Web Technologies", Astana IT University.
Assignment 1: anatomy of a web page, semantic HTML, tables, forms.

## Team

- Abylay Utemis — services.html, booking.html
- Rustem Gazymbekov — about.html, gallery.html
- index.html and colophon.html — made together

## Theme

**LOGOVO Barbershop** — a men's barbershop in Astana.
Address: Mangilik El 51/1. Working hours: 10:00–21:00, every day.
Phone: +7 700 396 8940. Email: logovo.barbershop@mail.ru

All data was collected during our visit on 13 September 2026: photos,
the price list and a video interview with senior barber Akhmadzhon Ibrokhimov.

## Repository structure

```
/
├── index.html      — home page
├── colophon.html   — how the site was made
├── services.html   — services and price list (Abylay)
├── booking.html    — booking form (Abylay)
├── about.html      — about us, interview with the barber (Rustem)
├── gallery.html    — photo gallery (Rustem)
├── images/         — our photos of the barbershop
├── checklist.md    — list of required tags with file and line numbers
```

## How to open

The site is plain HTML without CSS and JavaScript (as required by the assignment).
Just open `index.html` in a browser.

## Validation

Every page is checked with the [W3C validator](https://validator.w3.org/) — zero errors.
