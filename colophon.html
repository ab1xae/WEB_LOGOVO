About the Project

This website about the LOGOVO barbershop was made by Abylay Utemis and Rustem Gazymbekov. The site has six pages: the home page, this colophon and four personal pages. All the content is real: we went to the barbershop, took photos of the interior and recorded a video interview with the senior barber.

Technical Details

The site is written by hand in plain HTML, Every page was checked with W3C validator without errors.

This is the basic page skeleton we use on every page:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
</head>
<body>
    <header>...</header>
    <nav>...</nav>
    <main>...</main>
    <footer>...</footer>
</body>
</html>

To open a page in the browser press Ctrl + O, and to see the source code press Ctrl + U. If there are no errors, the validator shows this message: Document checking completed.

Tools We Used

We wrote the code in Visual Studio Code and kept the project in Git. The repository is on GitHub, and every student commits from his own account. The list of all required tags with line numbers is in the file checklist.md, and the project description is in README.md. All the real content (text, prices, the quote, photos) was collected by us during the visit to the barbershop.
